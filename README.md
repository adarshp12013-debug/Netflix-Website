## 📖 About

This project is a **frontend clone of the Netflix landing page**, developed to practice modern web design principles and responsive layouts using pure **HTML** and **CSS**.

The goal of this project was to recreate Netflix's sleek and professional interface while improving frontend development skills.

---

## ✨ Features

- 🎨 Clean and modern Netflix-inspired UI
- 📱 Fully responsive design
- 🎬 Hero section with call-to-action
- 📺 Feature showcase sections
- ❓ Frequently Asked Questions (FAQ)
- 📞 Footer with useful links
- ⚡ Lightweight and fast

---

## 🛠 Tech Stack

- HTML5
- CSS3
